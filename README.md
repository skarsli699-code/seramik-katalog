# Seramik Katalog

## Hızlı kurulum
1. GitHub'da `seramik-katalog` isimli Public repository oluşturun.
2. Bu klasördeki tüm dosyaları repository içine yükleyin.
3. `index.html` içindeki `WHATSAPP_NUMBER` alanını kendi numaranızla değiştirin.
   Örnek: 905551112233
4. GitHub > Settings > Pages bölümüne girin.
5. Source: Deploy from a branch
6. Branch: main / root
7. Save

Site adresiniz birkaç dakika içinde oluşur.

## Günlük ürün güncelleme
1. `admin.html` dosyasını bilgisayarda açın.
2. Mevcut `products.json` dosyasını seçin.
3. Ürün ekleyin veya silin.
4. Yeni `products.json` dosyasını indirin.
5. GitHub'daki eski dosyanın yerine yükleyin.

## Sipariş takibi
`orders.json` içindeki kayıtları güncelleyin.
Müşteriye yalnızca sipariş takip kodunu verin.
Müşteri adı, telefon veya açık adresi bu dosyaya yazmayın.
